# Portfólio — Carlos Daniel

Site pessoal desenvolvido em HTML, CSS e JavaScript.

## Como visualizar

Abra `index.html` no navegador. Mantenha `style.css` e `script.js` na mesma pasta.

## Publicar no GitHub Pages

1. Envie todos os arquivos e pastas deste projeto para um repositório no GitHub.
2. Acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)` e salve.

## Estrutura

- `index.html`: conteúdo do portfólio.
- `style.css`: estilos, layout responsivo e animações dos circuitos.
- `script.js`: interações do menu e efeitos de entrada.

## Personalização

Edite os textos, links e projetos diretamente no `index.html`. O elemento de processador e circuitos da página inicial é construído com HTML, CSS e SVG inline, sem depender de uma imagem externa.
